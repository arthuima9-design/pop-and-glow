## 🌐 วิธีนำเกมขึ้น GitHub และเปิดให้ทุกคนเล่นผ่านลิงก์ฟรี (GitHub Pages)

### แพลตฟอร์มที่แนะนำที่สุด: **GitHub Pages**
- **ฟรี 100% ตลอดชีพ** ไม่จำกัดแบนด์วิดท์
- **มี HTTPS อัตโนมัติ**: สำคัญมากเพราะกล้องตรวจจับมือ (Camera) และไมโครโฟนตรวจจับลมเป่า (Mic) บน iPad/iPhone บังคับว่าต้องรันบนเว็บที่เป็น `https://` เท่านั้น
- **อัปเดตง่าย เข้าลิงก์เดิมได้ตลอดกาล**: เมื่อแก้โค้ดหรืออัปเดตเกมบน GitHub ตัวเว็บจะอัปเดตตัวเองอัตโนมัติภายในไม่กี่วินาที ทุกคนเข้าลิงก์เดิมก็จะได้เล่นเวอร์ชันล่าสุดทันที

---

### ขั้นตอนการนำขึ้น GitHub (ทำได้ใน 3 นาที)

1. เข้าเว็บไซต์ [https://github.com](https://github.com) และลงชื่อเข้าใช้ (หากยังไม่มี ให้สมัครฟรี)
2. กดปุ่ม **New Repository** (สร้างคลังโปรเจกต์ใหม่)
   - ตั้งชื่อ เช่น `pop-and-glow`
   - เลือกเป็น **Public** (สาธารณะ เพื่อให้ทุกคนเปิดเล่นได้)
   - กด **Create repository**
3. อัปโหลดไฟล์ทั้งหมด:
   - กดที่ **uploading an existing file**
   - ลากไฟล์และโฟลเดอร์ทั้งหมดจากในเครื่อง (`d:\AI\เกมเสริมพัฒนาการ\`) ไปวาง:
     - `index.html`
     - `manifest.json`
     - โฟลเดอร์ `css/`
     - โฟลเดอร์ `js/`
     - โฟลเดอร์ `assets/`
   - กด **Commit changes**
4. เปิดใช้งาน GitHub Pages:
   - ไปที่แท็บ **Settings** ของ Repository นั้น
   - เมนูด้านซ้าย เลือก **Pages**
   - ในหัวข้อ **Branch** ให้เลือก `main` (หรือ `master`) แล้วโฟลเดอร์เป็น `/(root)`
   - กด **Save**
5. **รับลิงก์สำหรับส่งให้ทุกคนเล่น**:
   - รอประมาณ 1-2 นาที จะได้ลิงก์ เช่น:
     `https://<ชื่อผู้ใช้ของคุณ>.github.io/pop-and-glow/`
   - ส่งลิงก์นี้ให้เพื่อน คุณพ่อคุณแม่ หรือเปิดบน iPad/มือถือ ได้ทันที!

## 👤 ระบบ "เซฟใครเซฟมัน" (Profile & Save System)

ตัวเกมมีระบบบันทึกความคืบหน้ารองรับเด็กหลายคนและข้ามเครื่องอย่างสมบูรณ์:

1. **โปรไฟล์เฉพาะของเด็กแต่ละคน**:
   - สามารถสร้างโปรไฟล์แยกตามชื่อน้องได้ เช่น *"น้องมีนา"*, *"น้องภูผา"*
   - ตั้งรหัส **PIN 4 หลัก** ได้ เพื่อป้องกันไม่ให้พี่น้องสลับโปรไฟล์กันโดยไม่ตั้งใจ
   - แต่ละโปรไฟล์จะจำ:
     - จำนวนดวงดาวที่สะสมได้ ⭐
     - ด่านสูงสุดที่ปลดล็อคแล้ว
     - ถ้วยรางวัลที่ได้รับ 🏆
2. **ระบบย้ายเซฟข้ามเครื่อง (Save Sync Code)**:
   - อยู่ในเมนูตั้งค่าสำหรับผู้ปกครอง:
     - **📋 คัดลอกรหัสเซฟ**: กดยกเซฟของน้องเป็นรหัสข้อความสั้นๆ เช่น ส่งทาง LINE เข้ามือถืออีกเครื่อง
     - **📥 ใส่รหัสเซฟเล่นต่อ**: วางรหัสในเครื่องใหม่ ข้อมูลดาวและด่านของน้องจะถูกกู้คืนมาเล่นต่อได้ทันทีโดยไม่ต้องตั้งเซิร์ฟเวอร์ฐานข้อมูลให้ยุ่งยาก
3. **เมื่อเกมมีอัปเดต**:
   - ตัวเกมติดตั้งระบบ **Cache-Busting (`?v=1.2.0`)** ไว้แล้ว เมื่อเปิดผ่านลิงก์เดิม เบราว์เซอร์จะโหลดโค้ดเวอร์ชันล่าสุดเสมอ ข้อมูลเซฟเดิมของเด็กจะไม่สูญหาย
